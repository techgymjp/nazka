# ナスカの地上絵をスティンガー砲で

ペルー・ナスカ平原を舞台にした 3D シューティングゲームです。
砂漠に描かれた **実在の地上絵（19種）** が、プレイヤーから見ていろいろな方角・距離で **垂直に立ち上がり**、的になります。
一定時間で倒れて地上絵に戻ってしまうので、その前にスティンガーで撃ち抜きましょう。全部撃ち抜いたらゲームセットです。

▶ プレイ: https://techgymjp.github.io/nazka/

## 遊び方
| 操作 | PC | スマホ |
|---|---|---|
| 移動 | `W` `A` `S` `D`（`Shift` でダッシュ） | 画面左側をドラッグ |
| 照準（方位・仰角） | マウス（`↑` `↓`・ホイールで仰角の微調整） | 画面右側をドラッグ / ▲▼ ボタン |
| 発射 | クリック / `Space` | FIRE ボタン |

- 照準を地上絵の線に重ねるとシーカーが捕捉 → **ロックオン**し、ミサイルが誘導されます。
- 撃ち抜くたびに、その地上絵の紹介カードが表示されます。タイトル画面とリザルト画面の「図鑑」で一覧も見られます。

## スコア
- 撃破ボーナス：1体 1,000 点
- タイムボーナス：10分から短縮した秒数 × 40
- 命中率ボーナス：命中率² × 15,000
- 取り逃がしペナルティ：地面に戻ってしまった回数 × −500

## 登場する地上絵
ハチドリ、サル、クモ、コンドル、シャチ、宇宙飛行士、ペリカン、サギ（フラミンゴ）、オウム、イヌ、トカゲ、木、手、花、海藻、魚、渦巻き、ネコ、グンカンドリ

線画は実在の地上絵をもとにした簡略的な再現です。パンアメリカン・ハイウェイ（トカゲの地上絵を横切る）やミラドール（観測やぐら）と「木」「手」の位置関係も再現しています。

## 技術
- [three.js](https://threejs.org/) r160（`vendor/` に同梱、MIT License）
- 地形・テクスチャ・兵士モデル・効果音はすべてコードで生成しています（外部アセットなし）
- ビルド不要。静的ファイルのまま GitHub Pages で公開しています

ローカルで遊ぶ場合は、任意の静的サーバーで配信してください（ES Modules のため `file://` 直開きは不可）。

```bash
python3 -m http.server 8000
```
